📄 Dossier des PDFs

Placez vos fichiers PDF scientifiques dans ce dossier.

Une fois les PDFs ajoutés, utilisez l'interface web pour les indexer :
1. Ouvrez http://localhost:5173
2. Cliquez sur "Indexer les documents"
3. Explorez vos documents !

Types de documents recommandés :
- Articles scientifiques
- Rapports de recherche
- Thèses et mémoires
- Documentation technique
- Livres académiques

Format supporté : .pdf
